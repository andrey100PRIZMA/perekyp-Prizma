# Перекуп — React + TypeScript + Vite

## GitHub Pages
1. Создайте пустой GitHub repository.
2. Загрузите **все файлы и папки из этого проекта** в ветку `main`.
3. Откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Вкладка **Actions** → дождитесь `Deploy Perekup`.
5. GitHub Pages покажет адрес сайта.

Workflow сам устанавливает зависимости, собирает Vite и публикует `dist`.

## Локальный запуск
```bash
npm install
npm run build
npm run dev
```

## Supabase
В `src/supabase.ts` уже указаны URL и publishable key проекта. Сервисный ключ в браузер не добавляйте.
Перед облачным сохранением/промокодами выполните `supabase_promo_security.sql` в SQL Editor Supabase.

- ночной чёрный рынок;
