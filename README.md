# Перекуп — бизнес-симулятор (React + TypeScript + Vite)

Покупай дешевле → проверяй → продавай дороже. Игра про перекупа техникой:
площадки, гарантии, ремонт, сборка ПК, своя ОС, банк, бизнес и ночной чёрный рынок.

## Что нового в версии 7

**Дизайн**
- дизайн-система на CSS-переменных: радиусы, отступы, типографика в одном месте;
- три темы — «как в системе», светлая и тёмная (тёмная подобрана отдельно, не инверсия светлой);
- сайдбар с группами разделов и счётчиками-бейджами, нижняя навигация на телефоне;
- stat-плитки со спарклайном, прогресс-бары, тосты, модальные окна, скелетон загрузки;
- адаптив до 360 px, поддержка `prefers-reduced-motion` и компактного режима.

**График капитала**
- линия капитала по дням + столбцы дневной прибыли, тултип по наведению;
- переключатель «Показать таблицу» — значения доступны без чтения графика;
- цвета проверены на различимость при дальтонизме (CVD ΔE 9.2 светлая / 9.4 тёмная тема).

**Новые механики**
- **уровни и опыт**: 9 званий от «Новичка» до «Легенды рынка»;
- **ежедневные задания**: 5 целей в день с наградой деньгами и опытом, обновляются каждый день;
- **12 достижений** с условиями и иконками;
- **журнал событий**: что произошло, в какой день и час;
- **статистика** в профиле: покупки, продажи, лучшая сделка, ремонты и прочее;
- **случайные события** при прокрутке времени, проценты по кредиту, поломки по гарантии;
- **развитие ОС**: обновление версии приносит доход с пользователей;
- **лимит кредита** зависит от репутации.

**Фото и файлы**
- загрузка фото товара и аватара: клик или перетаскивание, сжатие через canvas
  (товар — до 512 px, аватар — квадрат до 256 px), хранение прямо в сохранении;
- заметка и своя цена продажи для каждого товара;
- **экспорт сохранения в JSON-файл** и импорт обратно (перенос между устройствами, резервная копия);
- импорт понимает и «сырой» файл, и строку из таблицы `game_saves` Supabase;
- совместимость со старыми сохранениями версии 6 — прогресс не теряется.

## GitHub Pages

1. Создайте пустой GitHub repository.
2. Загрузите все файлы проекта в ветку `main`.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Вкладка **Actions** → дождитесь `Deploy Perekup`.
5. GitHub Pages покажет адрес сайта.

Workflow сам устанавливает зависимости, собирает Vite и публикует `dist`.

## Локальный запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm run preview  # посмотреть сборку
```

## Проверки

```bash
npm test          # обе проверки
npm run test:logic # 41 проверка игровой логики
npm run test:ui    # 34 проверки интерфейса
```

`verify.mjs` собирает игровые модули через esbuild и прогоняет сценарии в Node:
время и дни, торговля, гарантии, ремонт, PC Lab, чёрный рынок, банк, ОС, задания,
уровни, достижения, сохранение и миграция старых форматов, 30-дневная симуляция.

`ui-check.mjs` монтирует настоящее приложение в jsdom, кликает по всем 14 экранам,
проверяет темы, модалки фото и импорта, запись в localStorage и отсутствие ошибок
в консоли. Supabase подменяется заглушкой из `test-stubs/`, поэтому тесты работают
без сети.

## Supabase

В `src/supabase.ts` указаны URL и publishable key проекта. Сервисный ключ в браузер
не добавляйте. Перед облачным сохранением и промокодами выполните
`supabase_promo_security.sql` в SQL Editor Supabase.

## Разделы игры

- первый экран: регистрация / логин / продолжение без аккаунта;
- локальное и облачное сохранение, экспорт и импорт файла;
- Market и Zono — площадки с отзывами и предложениями покупателей;
- официальный магазин: +5% к цене и гарантия 10 игровых дней;
- возврат по гарантии только после подтверждения неисправности;
- PC Lab: CPU/GPU/RAM/SSD, старые и новые комплектующие;
- SSD отличаются брендом, скоростью и надёжностью, дешёвые могут ломаться;
- лаборатория своей ОС с ядром, функциями и обновлениями;
- ночной чёрный рынок с розыском и штрафами;
- TechFix, ShipGo, FinBank, бизнес, задания, достижения и промокоды.
